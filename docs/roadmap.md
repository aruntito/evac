# EVAC Roadmap

## Phase 1 — Scenario model

- define scenario schema
- define network and population abstractions
- document assumptions and constraints

## Phase 2 — Simulation

- implement reproducible scenario runs
- model routing and congestion
- compare intervention strategies

## Phase 3 — Ecosystem research

- connect infrastructure context from GRID
- use disruption scenarios from the resilience branch
- publish reproducible research results

Operational use remains outside the project's current scope.
